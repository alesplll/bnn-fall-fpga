# ПР3 — прототип и измерение конвейера

`fpga_top.v` подаёт на классификатор 64 контрольных входа из `.mem`,
сверяет каждый ответ и выдаёт `done`, `pass`, `checked_count` и
`error_count`. Тестбенч проверяет успешный прогон, обнаружение
намеренной ошибки в эталоне и повторный запуск. `fpga_top_pipelined.v`
выполняет ту же проверку с конвейерным классификатором и подаёт новый
вектор каждый такт.

Для измерения вычислительного тракта служат
[`bnn_benchmark.v`](bnn_benchmark.v) и
[`tb_bnn_benchmark.v`](tb_bnn_benchmark.v). У исходного и конвейерного
вариантов одинаковый входной регистр, модули слоёв A/B, интерфейс,
веса, кристалл и тактовые ограничения. Признаки поступают извне и могут
меняться. Поэтому постоянный набор из 64 векторов верхнего модуля не
приводит к сокращению измеряемой логики. Сравниваются результаты
**после трассировки**: LUT, регистры, худший путь, WNS, период и
пропускная способность. Изменение задержки одного ответа отмечается
отдельно.

В проекте используется только ограничение тактового сигнала.
Назначений выводов платы, битового потока и физической проверки нет.

Пошаговый запуск в Vivado 2022.2 и состав файлов для отчёта приведены
в [`vivado/README.md`](../vivado/README.md).
