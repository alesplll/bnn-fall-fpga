# bnn-fall-fpga

Бинарный нейросетевой классификатор для детектирования падения
человека по данным инерциальных датчиков (акселерометр + гироскоп),
с аппаратной реализацией классификатора на ПЛИС.

Пять признаков (пиковое ускорение, угол наклона, пиковая угловая
скорость, jerk, дисперсия после пика — см. [`model/README.md`](model/README.md))
извлекаются из сигнала и подаются на маленькую бинарную нейросеть
5→8→1: первый слой — fixed-point (int8), второй — истинно бинарный,
считается через XNOR + popcount вместо умножения. Это сделано
специально, чтобы классификатор был дёшев в железе: без умножителей,
без плавающей точки.

## Что где лежит

- **[`model/`](model/)** — код модели: обработка датасета SisFall,
  извлечение признаков, обучение бинарной сети (NumPy,
  BinaryConnect/STE), её точная целочисленная реализация и метрики
  качества. Всё воспроизводимо с нуля (`model/README.md`).
- **[`dataset/`](dataset/)** — готовый датасет для обучения/проверки:
  один csv, где каждая строка — уже посчитанные 5 признаков + метка
  класса (не сырые сигналы). Описание колонок — в `dataset/README.md`.
- **[`weights/`](weights/)** — результат обучения в виде, готовом для
  аппаратной части: квантованные веса (`.mem`, hex, `$readmemh`) и
  эталонные тестовые векторы (вход → ожидаемый выход) для сверки
  результатов симуляции и работы в железе. Формат каждого файла
  расписан в `weights/README.md`.
- **[`rtl/`](rtl/)** — схема: реализация классификатора на уровне
  регистровых передач (Verilog), сверяется по файлам из `weights/`.
- **[`fpga/`](fpga/)** — прототип на ПЛИС: проект Vivado, констрейны
  под отладочную плату, загрузка и проверка в железе.

Веса самой сети крошечные (57 параметров, ≈77 байт «сырых» данных —
почти вся сложность в признаках, а не в модели), поэтому файлы в
`weights/` — это в основном удобочитаемый hex-текст для `$readmemh`,
не бинарная упаковка.

## Поток данных

```
SisFall (сырые данные) -> model/ -> dataset/ (признаки)
                              |    -> weights/ (веса + эталон) -> rtl/ -> fpga/
                        обучение и валидация модели
```

`model/` — единственная часть, где есть Python/NumPy и обучение.
Дальше по цепочке всё воспроизводится строго по датасету, весам и
тестовым векторам из `dataset/` и `weights/`, без переобучения.
