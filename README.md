# Классификатор падений 5→8→1 для ПЛИС

Проект объединяет программную модель, RTL-классификатор и прототип с
самопроверкой. Пять подготовленных признаков движения упаковываются в
40-битное слово. Первый слой вычисляет восемь знаковых сумм произведений
`int8`, второй сравнивает восемь бит активации с бинарными весами через
XNOR и подсчёт совпадений.

| Каталог | Содержимое |
| --- | --- |
| [`model/`](model/) | Извлечение признаков, обучение и целочисленный эталон |
| [`dataset/`](dataset/) | Готовые признаки и метки SisFall |
| [`weights/`](weights/) | Веса, входные векторы и ожидаемые ответы для Verilog |
| [`rtl/`](rtl/) | Исходный и конвейерный классификаторы, слои A/B и тестбенчи |
| [`fpga/`](fpga/) | Прототипы, тестбенчи и общий модуль для сравнения скорости |
| [`vivado/`](vivado/) | Один проект Vivado 2022.2 и воспроизводимый прогон |
| [`report/`](report/) | Единый отчёт ПР1–ПР3 и подтверждающие материалы |
| [`defense/`](defense/) | Пояснения к коду и защите |

ПР2 проверяет целочисленную RTL-модель по 2331 эталонному вектору. ПР3
добавляет верхний модуль, который самостоятельно подаёт 64 контрольных
вектора, выявляет расхождения и показывает результат проверки. Отдельно
сравниваются два вычислительных тракта с одинаковыми слоями: между
слоями A и B добавлен регистр, поэтому важны и частота после
трассировки, и задержка отдельного ответа.

Один проект для обеих работ создаётся командой `source vivado/run_all.tcl`
в Tcl Console Vivado 2022.2. Точная процедура, состав отчётов и границы
сравнения описаны в [`vivado/README.md`](vivado/README.md). Кристалл —
`xc7a100tcsg324-1`; распиновка платы и битовый поток не требуются.
