# ПР2 — RTL-классификатор

`bnn_classifier.v` вычисляет сеть 5→8→1. Входные пять признаков уже
подготовлены и квантованы программной моделью; каждый занимает один
знаковый байт в `input_features[39:0]`. Вычисление признаков из сырых
датчиков не входит в RTL.

Слой A: для каждого из восьми нейронов суммируются пять знаковых
произведений `int8 × int8` и 32-битное смещение. Бит активации равен 1
при сумме не меньше нуля. Слой B: XNOR битов активации и бинарных весов,
подсчёт совпадений, затем `score = 2 × число_совпадений − 8 + b_B`.
`fall_detected` и `valid_out` записываются по фронту такта. Четыре
`.mem` файла загружают веса и смещения через `$readmemh`; формат описан
в [`weights/README.md`](../weights/README.md).

`tb_bnn_classifier.v` проверяет 64 контрольных, 2331 полных либо 14
граничных векторов. В полном и граничном режиме сверяются также восемь
бит слоя A и числовой результат слоя B. Ожидаемый выход — результат
целочисленной программной модели, а не исходная метка датасета.

Конвейерный вариант состоит из [`bnn_layer_a.v`](bnn_layer_a.v),
[`bnn_layer_b.v`](bnn_layer_b.v) и
[`bnn_classifier_pipelined.v`](bnn_classifier_pipelined.v). Между слоями
на фронте такта сохраняются восемь бит и сигнал достоверности. Оба
варианта принимают один вектор каждый такт; конвейер добавляет один
такт задержки отдельного ответа. Тестбенч проверяет 2331 вектор и
промежуточные значения.

Для воспроизведения проекта Vivado 2022.2 и получения отчётов ПР2/ПР3
используется [единый сценарий](../vivado/README.md).
