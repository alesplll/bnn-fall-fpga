# dataset

Готовый датасет для обучения/проверки классификатора: 5 признаков,
извлечённых из сырых записей SisFall (акселерометр + гироскоп),
с меткой класса. Это уже посчитанные числа — не сырые сигналы; как
именно они считаются, см. `model/src/features.py` и формулы в
`model/README.md`.

## sisfall_5features.csv

11839 строк, одна строка = одно окно анализа (один локальный пик
ускорения в записи).

| Колонка | Тип | Описание |
|---|---|---|
| `subject` | str | ID испытуемого из SisFall (например `SA01`, `SE04`) |
| `split` | str | `train` (30 испытуемых, 9508 строк) / `test` (8 испытуемых, 2331 строка) — разбиение по испытуемым, не по окнам |
| `code` | str | код активности: `D01`–`D19` — обычная активность, `F01`–`F15` — падение |
| `trial` | str | номер попытки (`R01`, `R02`, ...) |
| `peak_idx` | int | индекс пикового отсчёта внутри исходной записи (200 Гц) |
| `label` | int | 1 = падение, 0 = обычная активность |
| `peak_acc_g` | float | признак 1: пиковое результирующее ускорение, g |
| `tilt_deg` | float | признак 2: угол наклона тела относительно начальной ориентации, ° |
| `peak_gyro_dps` | float | признак 3: пиковая угловая скорость, °/с |
| `jerk_g_per_s` | float | признак 4: скорость изменения ускорения, g/с |
| `post_peak_var_g2` | float | признак 5: дисперсия ускорения через 0.5–1.5 с после пика, g² |

Классы несбалансированы (1798 падений / 10041 не-падений, ~15/85 %) —
это ожидаемо, протокол SisFall предусматривает больше сценариев
обычной активности, чем падений.

Файл сгенерирован `model/src/dataset.py` (воспроизводимо, фиксированное
разбиение по `TEST_SUBJECTS` в том же файле) и полностью независим —
все признаки уже посчитаны, сырые данные датчиков для его
использования не нужны.
